# Changelog

## 0.0.1 — validated M0 foundation — 2026-10-03

- Added the Python API, versioned contracts, workspace-scoped migration and immutable fixture snapshots.
- Added Redis/Celery delivery with PostgreSQL outbox recovery, receipt leases, ownership fencing,
  exact LangGraph checkpoint handoff and idempotent runner jobs.
- Added shared sandbox reservations, private controller API, hardened Python/Node containers,
  strict TypeScript checks, immutable evaluators, bounded log artifacts and cancellation cleanup.
- Added the actual-state React interface with replayable activity, source evidence, Monaco diff,
  patch export, mixed partial results and responsive/keyboard interactions.
- Locked compatible Python, frontend and trusted compiler dependencies; added reproducible Compose
  setup, GitHub Actions, ADRs, threat model, stability policy and execution evidence.
- Passed 17 real architecture tests, 9 unit tests and 2 browser tests locally. Preserved reproduced
  failures and correction evidence. R1/R2 and later milestones remain unfinished.

See [progress](docs/progress.md) for continuation and [gate report](docs/architecture/gate-report.md)
for the exact acceptance scope. Public source hosting is separate from the application's
future GitHub PR publication feature.
